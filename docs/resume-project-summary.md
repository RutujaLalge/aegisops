# Resume Project Summary — draft

## AegisOps — AI-Powered DevOps Incident & Remediation Platform

Built a production-style AWS GenAI platform using Terraform, Amazon EKS, Docker, GitHub Actions
and Amazon Bedrock to assist DevOps engineers with incident investigation, RAG-grounded
root-cause analysis and controlled remediation.

### Resume bullets after implementation
- Provisioned reusable AWS infrastructure using Terraform modules for networking, EKS, ECR,
  IAM, storage and observability.
- Containerized TypeScript microservices with Docker and deployed them to Amazon EKS using
  Kubernetes deployments, health checks, resource controls and autoscaling.
- Implemented RAG-based incident analysis using Amazon Bedrock and operational runbooks/
  historical incidents stored in an AWS-managed knowledge workflow.
- Built CI/CD automation for testing, container image publishing, infrastructure validation
  and Kubernetes deployment.
- Implemented approval-gated remediation workflows with least-privilege IAM and post-action
  health verification.
- Added CloudWatch observability and a GenAI evaluation workflow covering retrieval quality,
  groundedness, latency and operational outcomes.
